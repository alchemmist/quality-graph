# Security policy

Quality Graph is pre-release software. Report suspected vulnerabilities privately through
GitHub's security advisory interface for `alchemmist/quality-graph`. Do not open a public issue
for an unpatched vulnerability.

Include the affected commit, generated workflow, event type, permission set, and a minimal
reproduction without real credentials or secret values.

The project currently supports no secret-bearing pull-request execution. Reports that require
enabling secrets or write permissions in untrusted jobs are outside the supported threat model.
